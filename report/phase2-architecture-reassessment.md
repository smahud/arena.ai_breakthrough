## Functional architecture supported; internal architecture not discriminated

1. An **external plan/dependency artifact** preceded implementation; backend/UI edits on disjoint files followed; tests and HTTP checks followed their prerequisites. EXP-11's scripted Tier-2 conflict respected the prior C3 default API constraint, but the design itself forced this check. This supports goal decomposition, sequencing and conflict annotation as observable functions, **not** an internal standalone planner.
2. **Tool call/return dispatch and validation** are externally evidenced: F-16's historical near-serial intervals and F-20's explicit-wrapper overlap are both valid; the matched exploratory N/d control narrows workload-only explanation. Tool-category completion times do not reveal independent workers. The security gate F-22 found and fixed a real baseline artifact defect; it does not demonstrate a specialist generator.
3. **External state and bounded recovery** are evidenced by the Tier-1 patch/checkpoint: after a genuine user-turn loss of an excluded fixture, five + two recorded hashes were recreated and tests repeated. This is artifact-based state management, **not** a fresh-chat memory, automatic context compaction, or hidden model adaptation claim.

A1 (single generative loop), A2 (planner/executor split) and A3 (specialists) can each reproduce **all** observed tool/result sequences. H-A4 adaptive behavior was seen functionally, but one fixed contingent policy could reproduce it. No supported tool exposed private message boundaries, prompts, model identifiers or router decisions; those remain UNKNOWN, not inferred from writing style, quality or latency. The public product descriptions do not collapse this distinction.

**Reference implementation decision:** keep `src/minagent` and its `ThreadPoolExecutor` toy in-process concurrency **unchanged**; no new agent, message bus, model-router abstraction or database is justified by Phase-2 evidence. `minagent`'s parallelism is a separate *implementation choice*, not proof of the platform's mechanism. Port only the **verified** static-file containment correction in main taskledger plus regression test (F-22).
