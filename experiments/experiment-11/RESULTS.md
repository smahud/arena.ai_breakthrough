# Experiment 11 — RESULTS (heterogeneous workload, scripted change, security gate, genuine user turn)

**Design frozen before execution:** `DESIGN.md` at commit `9430392` (Phase-2 plan). **Question:** What is externally observable about coordinating research, architecture, backend/frontend, tests, security, documentation, integration, a controlled change, recoverable failures, and state recovery? **Fixture baseline:** audit commit `c0caa6e`, deliberately separate from main repo source. **Raw ledgers:** [`../../evidence/phase2/exp11-events.md`](../../evidence/phase2/exp11-events.md), separate logs below. No platform-internal planner or model identity was accessed.

## Variables, controls, and procedure

Independent variables: task category, initial vs expanded requirement tier, deliberately introduced Tier-2 regression tests, harmless security path probe, *actually observed* user-turn boundary. Controlled: the same detached base commit, C1 stdlib-only runtime, C2 inline frontend, C3 unchanged unqualified task list, C4 `textContent`, original 44 tests unchanged, no external services or `minagent` changes. The initial fixture lived in snapshot-excluded `.cache` (an **unanticipated** persistence failure); after the real user continuation, it was reconstructed in a non-excluded directory from the persisted Tier-1 patch and logged edits. This is **one case study**, not multiple independent agent runs.
